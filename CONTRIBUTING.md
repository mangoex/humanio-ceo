# Contribuir

1. Crear una rama desde `main`.
2. Mantener los cambios dentro de un incremento verificable.
3. Actualizar especificaciones y pruebas cuando cambie comportamiento.
4. Ejecutar `python3 scripts/humanio.py doctor`.
5. Ejecutar `python3 -m unittest discover -s tests -v`.
6. Validar el plugin y cada skill.
7. Abrir un pull request con impacto, evidencia y riesgos.

No incluir credenciales, datos personales, evidencia ficticia ni fixtures de clientes reales.
