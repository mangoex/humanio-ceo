# Guía de Sesión de Diagnóstico CEO

## Objetivo de la sesión

Identificar un caso de uso viable para un agente de IA y levantar la información mínima para diseñarlo bajo el CEO Framework.

Duración sugerida: 60 a 90 minutos.

## Participantes recomendados

- Responsable del área que vive el problema.
- Persona que ejecuta el proceso hoy.
- Responsable de sistemas o herramientas.
- Tomador de decisión.
- Consultor Humanio.

## Agenda

| Minutos | Bloque | Objetivo |
| --- | --- | --- |
| 0-10 | Apertura | Alinear expectativa y resultado de la sesión |
| 10-25 | Dolor de negocio | Entender problema, impacto y prioridad |
| 25-40 | Proceso actual | Mapear cómo se trabaja hoy |
| 40-55 | Contexto | Identificar información, reglas y límites |
| 55-70 | Ecosistema | Revisar canales, sistemas, datos y personas |
| 70-85 | Orquestación | Definir acciones, escalamiento y medición |
| 85-90 | Cierre | Acordar siguiente paso |

## Preguntas clave

### Negocio

- Qué problema quieren resolver.
- Qué costo tiene no resolverlo.
- Qué indicador debería mejorar.
- Qué caso de uso sería más valioso si se automatiza parcialmente.

### Contexto

- Qué debe saber el agente para responder bien.
- Qué documentos o fuentes existen.
- Qué reglas debe respetar.
- Qué temas no debe tocar.
- Cuándo debe reconocer que no sabe.

### Ecosistema

- Dónde interactuará el usuario.
- Qué herramientas se usan hoy.
- Qué datos se deben consultar o registrar.
- Quién debe recibir casos escalados.
- Qué integraciones son obligatorias y cuáles pueden esperar.

### Orquestación

- Qué pasos puede hacer el agente solo.
- Qué pasos requieren aprobación humana.
- Qué estados debe tener el proceso.
- Qué eventos deben guardarse.
- Cómo se medirá si funcionó.

## Cierre recomendado

Al final de la sesión, Humanio debe poder entregar:

- Caso de uso priorizado.
- Riesgos principales.
- Datos e integraciones mínimas.
- Recomendación de primer prototipo.
- Próximo paso concreto.
