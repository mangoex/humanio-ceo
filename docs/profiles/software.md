## Cobertura

- Problema, alcance, exclusiones y personas.
- Requisitos funcionales y no funcionales.
- Arquitectura, módulos, datos, contratos y estados.
- Seguridad, observabilidad, migraciones y despliegue.
- BDD observable.
- TDD por nivel.
- Trazabilidad hasta código y evidencia.

## Estrategia

Crear primero una cobertura vertical mínima y coherente. Profundizar después por capacidad sin dejar BDD, TDD o trazabilidad vacíos.
