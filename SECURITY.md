# Seguridad

No publicar secretos, datos personales ni detalles explotables en issues, ejemplos o fixtures.

Para reportar una vulnerabilidad, contactar de forma privada al propietario del repositorio antes de abrir una discusión pública. Incluir versión, impacto, reproducción mínima y mitigación propuesta.

El mantenedor debe confirmar recepción, clasificar severidad, definir contención y publicar una corrección sin exponer información sensible innecesaria.
